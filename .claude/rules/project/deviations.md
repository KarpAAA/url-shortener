# Project deviations from nest-conventions

This service is a small public URL shortener with no users and no async work. Each deviation
below is deliberate; the trigger says when the shared rule applies again.

| #   | Shared rule                                                                                                                                               | Here                                                                                                                                  | Why                                                                                                             | Trigger to revert                                                   |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| 1   | `http/error-handling.md` §3: `{code, message, details, correlationId}`                                                                                    | RFC 9457 `application/problem+json`: `type`, `title`, `status`, `detail`, `instance` + extensions `code`, `correlationId`, `errors[]` | the task requires RFC 9457; hierarchy, single filter and stable `code` are kept                                 | never — a superset of the shared shape                              |
| 2   | `_core/principles.md` #2, #3: `Actor` on every use case, policy inspects it                                                                               | no `Actor`, no policy, no guards                                                                                                      | no authentication; an always-allow policy is code with no rule                                                  | the first endpoint that needs an identity                           |
| 3   | `domain/ports-adapters.md` §4: repository ports are rare; fakes only for outbound services                                                                | `LinkRepository` port + in-memory fake                                                                                                | use-case tests (collision retries, round-trip property) and Stryker on `application/` run without Docker        | never needed to revert; drop the fake if use-case tests move to e2e |
| 4   | `http/api-conventions.md` §1–2: `/v1`, plural nouns, UUID ids in paths                                                                                    | `/shorten`, `/:code`, `/stats/:code`, no version prefix                                                                               | the task fixes the paths; short links must stay short                                                           | a breaking API change                                               |
| 5   | `data/db-general.md` §7: no `UPDATE … SET n = n + 1` per request; Redis `INCR` + flush                                                                    | one atomic `UPDATE … SET visits = visits + 1` in Postgres                                                                             | exact counts, no Redis in scope                                                                                 | redirect p95 or row contention on hot links — see `docs/scaling.md` |
| 6   | `ops/security.md` §2: throttler with Redis storage                                                                                                        | in-memory throttler on `POST /shorten`                                                                                                | single instance; Redis for one counter is over-engineering                                                      | the second replica                                                  |
| 7   | `ops/process-model.md` §1: `api` + `worker` from day one                                                                                                  | `api` only                                                                                                                            | no queue, no cron, no outbox                                                                                    | the first asynchronous job                                          |
| 8   | `http/api-conventions.md` §7: Swagger off or guarded in production                                                                                        | `/docs` and `/docs-json` always public                                                                                                | public API; the contract is the product and Schemathesis reads it                                               | an internal-only deployment                                         |
| 9   | `ops/observability.md` §4: readiness checks DB and Redis                                                                                                  | DB only                                                                                                                               | no Redis                                                                                                        | Redis is added                                                      |
| 10  | `ops/observability.md` §1–3: prom-client, OTel, alert rules from day one                                                                                  | structured logs + health only                                                                                                         | out of the task's scope; described in `docs/scaling.md`                                                         | the first SLO                                                       |
| 11  | `application/write-service.md` §2, `domain/repository-mapper.md` §1: use case returns `void` / `{id}`; repository is `findById`/`getById`/`insert`/`save` | `ResolveLinkService` returns the target URL; repository is `insert` + `registerVisit`                                                 | load → mutate → save is a read-modify-write that loses visits; one `UPDATE … RETURNING` does both               | never                                                               |
| 12  | `quality/git-pr.md` §3: `main`, PR only                                                                                                                   | `master`, direct push                                                                                                                 | new repository, single author                                                                                   | a second contributor                                                |
| 13  | `application/write-service.md` §1: `@UseCase()` adds log, metric, span                                                                                    | `@UseCase()` adds the log line only                                                                                                   | follows #10                                                                                                     | with #10                                                            |
| 14  | `http/controller.md` §4: error responses documented once, globally                                                                                        | per endpoint, through `@ApiProblemResponse`                                                                                           | Schemathesis checks each endpoint's statuses against the schema, so each must list exactly what it returns      | the fuzzer is dropped                                               |
| 15  | `_core/principles.md` #1: a module exports only its facade                                                                                                | `LinksModule` exports its two use cases and the query service                                                                         | they are consumed only by the module's own transport module; with no second module a facade is an empty wrapper | a second business module                                            |
